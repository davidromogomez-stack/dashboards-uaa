# Tableros del equipo UAA · Datatón INEGI 2026 (reto ANTAD)

Sitio publicado con GitHub Pages:

- `index.html`: portada con los dos tableros
- `consumo.html`: Consumo electrónico en México (ENDUTIH 2020–2025 y ENIGH 2020–2024)

Fuente: INEGI, microdatos ENDUTIH, ENIGH y DENUE. Cálculos del equipo UAA.
